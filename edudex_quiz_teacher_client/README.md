# EduDex Quiz Teacher

Ứng dụng quản lý thi trắc nghiệm dành cho giáo viên và cán bộ coi thi, là một phần của hệ thống thi trắc nghiệm EduDex. Được phát triển bằng Flutter, ứng dụng này hoạt động trong mạng LAN và kết nối trực tiếp với EduDex Server.

## Tính năng chính

- **Quản lý ngân hàng câu hỏi**
  - Thêm, sửa, xóa câu hỏi trắc nghiệm
  - Nhập/xuất câu hỏi từ Excel
  - Hỗ trợ câu hỏi đa phương tiện (văn bản, hình ảnh, âm thanh, video)

- **Quản lý đề thi**
  - Tạo đề thi với nhiều tiêu chí
  - Sắp xếp câu hỏi ngẫu nhiên
  - Cấu hình thời gian thi
  - Phân phối đề thi tự động

- **Quản lý phòng thi**
  - Theo dõi danh sách thí sinh
  - Giám sát tiến độ làm bài
  - Mở/khóa bài thi theo phòng hoặc cá nhân
  - Xử lý sự cố trong quá trình thi

- **Bảo mật cao**
  - Mã hóa dữ liệu end-to-end
  - Hoạt động độc lập trong mạng LAN
  - Phát hiện và ngăn chặn gian lận
  - Sao lưu dữ liệu tự động

## Yêu cầu hệ thống

- Windows 7 trở lên (64-bit)
- RAM: 4GB trở lên
- Kết nối mạng LAN ổn định
- Độ phân giải màn hình tối thiểu: 1366x768

## Cài đặt

1. Tải về bản cài đặt mới nhất
2. Chạy file cài đặt với quyền Administrator
3. Khởi động và cấu hình kết nối với EduDex Server

## Hướng dẫn sử dụng

1. **Trước kỳ thi**
   - Chuẩn bị ngân hàng câu hỏi
   - Tạo đề thi
   - Nhập danh sách thí sinh
   - Phân chia phòng thi

2. **Trong kỳ thi**
   - Kích hoạt bài thi
   - Giám sát quá trình làm bài
   - Xử lý các sự cố phát sinh

3. **Sau kỳ thi**
   - Chấm điểm tự động
   - Xuất báo cáo kết quả
   - Phân tích dữ liệu thi

## Xử lý sự cố

- **Lỗi kết nối**: Kiểm tra cấu hình mạng và EduDex Server
- **Lỗi đồng bộ**: Sử dụng tính năng khôi phục dữ liệu
- **Sự cố máy thi**: Công cụ điều khiển từ xa để hỗ trợ

## Phát triển

Dự án được phát triển bằng:
- Flutter/Dart
- Giao thức TCP/IP
- Mã hóa SSL/TLS
- Cơ sở dữ liệu SQLite cho lưu trữ cục bộ
